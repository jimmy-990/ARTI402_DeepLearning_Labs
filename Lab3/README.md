# ARTI 402 — Deep Learning

## Lab 3 — CNN Architecture: The Four Building Blocks

This lab implements the four blocks of a CNN from scratch in NumPy (filtering, max pooling, flatten, fully connected). It then shows that the CNN handles shifted images when a dense network cannot.

**Results:** raw pixels with 435 params scored 0.333 on the test set. The CNN with global pooling used 15 params and scored 1.000.
