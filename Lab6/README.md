# ARTI 402 Deep Learning

Lab work for ARTI 402 built from scratch in NumPy

## Lab 6 Regularization

Closing the gap between training and validation on a small spiral dataset

- L1 and L2 penalties in the loss and the gradient
- Inverted dropout that turns off at test time
- He initialisation tested through a 10 layer network
- Batch norm forward pass
- Comparison of baseline vs L2 vs dropout vs both

L2 gave the best result with validation accuracy going from 0.683 to 0.750 and a smaller gap
