# ARTI 402 — Deep Learning

## Lab 1 — summary

Builds up from one neuron to a full batched layer, covering:

- Deep learning vocabulary: feature, sample, batch, label, weight, bias, layer
- Computing a single neuron in plain Python, then with `np.dot`
- Weights vs biases, and the step activation function
- A whole layer with loops, then vectorised with NumPy
- Array shapes, the dot product, and transposing for batched input
- Counting trainable parameters of a dense network
- Assessment: a forward pass through a two-layer network
