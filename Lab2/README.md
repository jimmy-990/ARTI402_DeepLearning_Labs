# ARTI402 Lab 2

This lab covers the basic building blocks of neural networks using NumPy.

## Topics Covered

- Matrix operations and combining neural network layers
- ReLU and Sigmoid activation functions
- Dense layer implementation
- Softmax activation
- Categorical Cross-Entropy loss
- Numerical derivatives
- Gradient Descent
- Backpropagation basics
- Building and training a small neural network classifier

## Final Model

The final model uses two dense layers with ReLU and Softmax activation functions.  
It is trained using numerical gradients and achieves more than 90% training accuracy.
